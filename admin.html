Set up admin access

This site is static — there is no server to log in to. Instead, this browser stores a GitHub token encrypted with a password you choose. You do this once per device; after that it is just the password.

Create a fine-grained personal access token at github.com/settings/personal-access-tokens, limited to this one repository, with Contents: Read and write. Give it an expiry date — you can always set it up again.
