## How it's built

**SerializableSelector** turns any `[SerializeReference]` field into a dropdown of the types that fit it, so polymorphic data (enemy behaviours, objectives, impact effects) is set up in the Inspector instead of in code. It finds every type that matches the field and its interface constraints, then groups them by category with names and tooltips.

**ObjectPooler** sets itself up before the first scene loads from a settings asset, pre-warms pools per scene, and exposes a small static API with generic versions that return the component you asked for.
