# PopACorn

<img src="https://danielnoam.github.io/portfolio/assets/popacorn/main.gif" alt="Game Screenshot">

<div class="project-card">

## Overview

"PopACorn" is a match-3 puzzle game developed during my fifth semester as a mobile-centric project with PC and WebGL support.
Players match colorful corn pieces on dynamic grid layouts, with gameplay optimized for touch controls while remaining fully playable on desktop platforms.

</div>

<div class="project-card">

## Core Design Elements

### Grid System

- Flexible grid architecture supporting various shapes and sizes for diverse level layouts.
- Custom editor tool enabling quick creation of unique grid configurations by selecting active cells.
- Modular design allowing rapid prototyping of different puzzle layouts and difficulty progressions.

### Mobile Experience

- Touch-optimized controls designed for mobile gameplay.
- Custom haptic feedback implementation providing tactile responses to player actions.
- Responsive interface that adapts seamlessly between mobile and desktop platforms.

</div>



<div class="project-card">

## Development Insights

- Built a flexible grid system from the ground up to support non-standard puzzle layouts.
- Created custom Unity Editor tools to streamline level design workflow, allowing designers to visually configure grid shapes.
- Implemented platform-specific haptic feedback for enhanced mobile experience while maintaining cross-platform compatibility.
- Designed with mobile-first approach while ensuring full functionality across PC and WebGL builds.
