# Dropped

Ideas decided against, with the reason. If the reason stops being true,
the idea can come back.

- **Rebuild on React, Tailwind, shadcn/ui and Framer Motion** (from the UI
  guide Daniel shared, 2026-10-05). The site is deliberately no-build; it
  would mean rewriting the router, content loader, lightbox, admin panel
  and backgrounds for weeks with nothing a visitor would notice. The guide
  is used as a checklist instead (contrast, focus states, spacing scale).
- **A profiling and texture atlasing section on Electro Grid**
  (2026-10-12). Adding a section to hit a job-ad keyword reads as padding.
  That work is real on Disney Solitaire and goes on that page.
- **Light mode for visitors** (1.5.1). It failed contrast and nobody chose
  it on purpose. The site is locked dark; `uiSettings.allowLightMode`
  brings it back once light mode is redone.
- **Electro Grid hover overlay** with pitch and Read more / Play buttons
  (1.6.0, removed 1.7.1). Replaced by the same role line as the other
  tiles; touch users never saw the hover anyway.
- **Titles on About tiles and Archived tiles** (1.6.0, 1.8.1). The images
  carry the names; a grey role line says more.
- **Animated pulsing gradient on School These Shits** and page backgrounds
  behind the sidebar (1.7.0). Generic motion competing with the work.
- **Emoji icons** (1.7.0). They render differently per device; replaced by
  inline Tabler SVGs.
- **Password login for the admin panel** (1.4.0). Typing a password on
  every visit was friction; replaced by token plus PIN or Face ID (1.5.0).
- **Long documentation-style project pages** (1.8.0). Chicken Invaders had
  15 subsections and 17 code blocks; the page recipe in CLAUDE.md replaced
  that shape.
- **First About text draft** (2026-10-05): Unity developer, Electro Grid,
  Disney Solitaire, DNExtensions, looking for a junior role. Rejected;
  the reason wasn't recorded, so ask before redrafting.
